# Donezo - Task Management System

## About
Donezo is a simple project and task management application. It allows users to create projects, assign tasks to members, and track deadlines using a clean 3-column board layout.

## Tech Stack
- **Frontend**: React + Vite
- **Backend**: NestJS
- **Database**: MongoDB (via Mongoose)

## Prerequisites
- **Node.js**: Installed on your machine.
- **MongoDB**: Must be running locally on port `27017`.

## How to Run

### 1. Backend
```bash
cd backend
npm install
npm run start:dev
```
*API will run at: http://localhost:3000/api*

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
*App will run at: http://localhost:5173*
